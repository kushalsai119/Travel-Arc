# TravelArc — Indian Travel & Local Guides Website

A multi-page website project created for our Web Programming course. It allows users to explore travel destinations across India, read traveler reviews, view profiles of local guides, and plan a trip through an inquiry form.

## Website Pages

* **Home (`index.html`)**: Main landing page with a hero banner, quick highlight cards, and featured travel destinations.
* **Places (`places.html`)**: An 8-destination card grid showing places like Kashmir, Kerala, Rajasthan, Goa, and Ladakh with photos and brief details.
* **Journal (`journal.html`)**: 6 travel reviews and stories shared by travelers who explored India with local guides.
* **Your Guides (`guides.html`)**: Directory of 6 regional local guides with their experience, specialty, and contact links.
* **Contact (`contact.html`)**: Trip planning form to choose a destination, select a preferred guide, and send an inquiry.

---

## Technologies Used

* **HTML5**: Semantic tags used for page structure (`header`, `nav`, `main`, `section`, `article`, `footer`, `form`).
* **CSS3**: Layout and design using Flexbox, CSS Grid, and CSS variables in `style.css`.
* **Zero JavaScript**: Pure HTML and CSS without any external libraries or frameworks.
* **Real Photos**: Authentic landmark photos used across destination cards, journal stories, and guide profiles.
